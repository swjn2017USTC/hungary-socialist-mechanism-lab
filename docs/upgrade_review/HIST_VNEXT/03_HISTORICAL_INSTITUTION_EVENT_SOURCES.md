## 必须保留的历史反证与竞争解释

1. [VERIFIED_BY_WEB] S04将部分对外债务数值标为非官方估计，不能拿来当精确债务真值；其改革评价带作者立场。IMF 1991回顾的制度评价同样不是中性的原始行政记录。二者可能引用共同统计，不能机械计算为两个独立观测。
2. [VERIFIED_BY_WEB] 贸易价格机制在1975前后变化，削弱“1973冲击立即、同幅进入所有CMEA购货”的方案。先检验合同滞后和国内调节，不把缓冲全部归因于政治承诺。
3. [HYPOTHESIS] 1957–67并非各行业统一的同一组织权限；农业合作化、行业差异和改革准备需要sector级时序。宏观四窗口只作检索目录。
4. [HYPOTHESIS] 银行授信、财政转移与外汇可得性不是同一种“资金”。账目守恒不能证明制度正确，额外信用也不证明消费得到维持。
5. [VERIFIED_BY_CODE] 63项1957锚目前登记但未接入初始化；KSH216是总量口径、另一202是人均口径（数字来自提供的独立诊断，**本轮不重开目标表**）。初始化/人口/价格权重误差应先于政治行为参数识别。

## 事件本体与加工协议 [HYPOTHESIS]

事件记录最少包含：`event_id, source_id, source_sha256, archival_reference, page, original_language, original_excerpt, translation, extraction_method, reviewer, document_date, enactment_date, effective_from, effective_to, observed_implementation_at, source_available_at, date_precision, issuer, legal_force, sector_scope, geographic_scope, authority_granted, authority_removed, information_rights, financing_channel, instrument, price_category, supersedes_event, implementation_evidence_id, competing_source_id, confidence_reason, rights_status, data_role, exposure_window, synthetic_flag`。

`confidence_reason`先给证据理由/分级，不伪造概率。每项事件至少链接“建议/会议→批准/法规→组织行动→实际交付/结算”，允许缺边，缺边就保持unknown。译文和OCR错误需回到原匈文页核验；LLM标注不可自动进入正式runtime。未知日期用区间和精度，禁止补成季度第一天。

历史知识库可以事后回顾完整文献；**模型主体**只读取在模拟决策时已可获得的内容，不能因为文献后来写明结局就赋予当时企业预知能力。政策有效时间与信息发布时间分别验证；未知的当时可用性不能默认为当时已知。
