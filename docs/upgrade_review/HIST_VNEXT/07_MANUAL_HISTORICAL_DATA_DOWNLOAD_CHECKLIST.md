# 修订计划：历史资料手动下载清单与最迟准备时间

日期：2026-10-15。对应 [05 修订实施计划](05_REVISED_IMPLEMENTATION_PLAN.md) 和 [06 OMP/MiniMax交接](06_OMP_MINIMAX_HANDOFF.md)，是新增的用户操作说明，**不替代或放宽原阶段门**。

本文按“你什么时候需要准备什么”排列。链接和访问状态沿用同日 [03 史料审计](03_HISTORICAL_INSTITUTION_EVENT_SOURCES.md) 及较早的 [来源清单](../03_DEPENDENCIES_AND_SOURCES.md)，本次只整理下载任务，**没有重新检测链接、下载史料或启动实施**。早先可读的地址也可能暂时失败；未取得原件的项目仍然是缺口。

## 先看这一页

**现在不用下载全套资料，也不用等资料齐全才修H0。**

1. **H0A/H0B前：不需要新增历史下载。** 使用现有仓库、原卡、运行输出和审计反例即可。
2. **开始H1A资料准入时：先准备两篇综述，并寻找1966/1968、1972–76的关键决议或法规原件。** H1A本身就是边收集边审查，不要求先凑齐下表所有资料。综述帮助找到原件，不能替代原件。
3. **H1B将制度规则标为历史事实前：必须有该条权限/价格/投资规则的原件及日期。** 找不到，可以做明确的synthetic规则声明；不能标成真实匈牙利制度。
4. **H3F做金融技术测试前：不必先下载1985汇率。** 若要把新融资制度称为历史制度，则需要银行/外贸授信、收款和清算依据；否则只能做合成对照。
5. **H4A接历史初态、H4B/H4C做历史pilot前：补齐初始锚原件、统计口径、相关制度执行和金融合同证据。** 这是最主要的历史资料硬门。
6. **H5/H6前：按实际要研究的卡补专题材料。** 不需要为一张卡先下载所有其他卡的资料；没有独立观测，就保留UNIDENTIFIED，不硬做历史估计。

“5–10份制度原件”只是第一批工作量建议，**不是文件数够了就验收**。每一条关键规则仍须有出处；每个历史pilot仍须有竞争解释和至少两个独立、可观察的历史模式。

## 第一批：现在最值得手动准备的材料

### 1. 两份背景研究，帮助找对原件（D01/D02）

这几份是**文献线索**。出版物可读/可保存不等于可再分发、可整本翻译发布或批量交模型加工；用途审核按03办理。本文不为其增加新许可判断。

### 2. 第一组制度原件：围绕1968与1972，而不是下载整个档案库（D03/D04/D16）

入口：

- [ ] 1965改革筹备/研究委员会的任命、任务或提交记录。
- [ ] 1966改革决议及其对应会议记录，保留最终决议与讨论稿的区别。
- [ ] 1968实施时关于**企业购销权限**的具体法规/规定。
- [ ] 关于**固定/受控/自由价格类别**及适用行业的规定。
- [ ] 关于**投资审批、信贷、利润/工资监管**的规定；可以是分别的文件。
- [ ] 1972年及其后相关调整的决议/部委规定，注明适用企业、行业及实施日期。

**不要只保存检索结果页。** 最有用的是可读原件、档号/文号、页码、日期；目录和议程也有价值，但只能先算检索线索。MNL该目录的中委子系列元数据只覆盖至1970，1972中委文件需另外定位，不能因为看见1971–80指南就认定原件已全部在线。

## 第二批：在H4A历史初态与口径接入前补齐

### D08：先盘点63项已登记锚，再补缺失

本地 `config/calibration/p05.json` 仍说明63项初始锚已登记/准入，但没有接入实际初始化。因此：

1. 先由后续资料审查核对已有原件、登记hash、表页、单位、年份和地区，给你一份**缺件名单**。
2. 你只需补缺失的原文/表头/方法页；不能把“尚未接入代码”理解成“全部必须重新下载”。
3. 1957全年产量不是1957年初库存；1956年末存量、1957年度流量、人口普查时点需要分开。

候选入口：[EPA匈牙利统计年鉴目录](https://epa.oszk.hu/html/vgi/kardexlap.phtml?aktev=1950&id=5300)。按需要寻找1956/1957卷、相邻年份方法页，以及独立人口/就业/住房资料。本文没有确认1956/1957具体PDF地址，**不臆造直链**。

### D09：投入产出、物资/运输资料

优先找：部门投入与产出、最终用途、进口处理、产能、货运/运输能力、库存和交付周期。所有表须带行业分类和计价基础。

可用书目线索：*A magyar népgazdaság ágazati kapcsolatainak mérlege, 1965–1968*（旧审计记录的投入产出表书目）。**这是馆藏检索线索，不是已确认免费PDF。** 找不到时需要图书馆/合法扫描，不能先补一个“看起来合理”的历史矩阵。

统计年鉴可从 [1968入口](https://epa.oszk.hu/html/vgi/kardexlap.phtml?aktev=1968&id=5300)、[1973入口](https://epa.oszk.hu/html/vgi/kardexlap.phtml?aktev=1973&id=5300)、[1975入口](https://epa.oszk.hu/html/vgi/kardexlap.phtml?aktev=1975&id=5300) 查相关表目录；**先看哪些卷有需要的表，不要求三卷全下。** 这些年度入口来自既有审计，本次未重测。

### D10：统计定义和必要的允许期表页

消费/价格/贸易资料先补“这个数字到底量了什么”，而不是再增加长时间序列：

- 家庭实际最终消费、家庭消费支出、总量、人均是否区别；是否含公共实物服务。
- 价格/物量权重、基期、单位、年度汇总、修订说明。
- 贸易数量/价值、进口/出口、币种、CMEA/可兑换渠道及交易汇率含义。
- GDP、投资、部门总产出和模型商品流之间的边界。

[KSH官网](https://www.ksh.hu/) 是查具体表与方法页的入口；[KSH版权页](https://www.ksh.hu/copyright_eng) 是资料伴随记录，不能套用到所有馆藏扫描。既有已准入目标先核登记版本，**不要为了“最新”把含封存年份的整张表重新下载给实施模型**。

若确实需要年鉴表页，[1960 PDF](https://epa.oszk.hu/05300/05300/00012/pdf/EPA05300_statisztikai_evkonyv_1960.pdf)、[1978 PDF](https://epa.oszk.hu/05300/05300/00030/pdf/EPA05300_statisztikai_evkonyv_1978.pdf) 可作候选直链：较早审计曾核到文件头，同日最新审计的EPA访问出现502，**当前能否下载及扫描许可仍待确认**。先索引页和相关表页，不要求现在取得两本整册。
